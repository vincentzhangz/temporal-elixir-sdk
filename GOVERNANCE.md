# Governance

The repository owner is the initial maintainer and release steward. Changes are
accepted through review against documented compatibility and conformance gates.
Maintainer membership, decision records, and release authority will be made
explicit before the first published package.

Protocol and behavioral decisions must cite official Temporal sources.
Architecture changes require an ADR. Protobuf upgrades require an upstream diff
review, regenerated checksums, the complete test suite, and replay/conformance
evidence appropriate to the implemented feature set.

This governance applies only to this community project. Temporal Technologies
does not maintain or endorse it.
